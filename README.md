# ResolveAI

**KI-gestützter IT-Support für Unternehmen**

ResolveAI hilft Mitarbeitenden bei alltäglichen IT-Problemen. Die KI analysiert Anfragen in natürlicher Sprache, stellt Rückfragen und schlägt Lösungsschritte vor. Bleibt ein Problem ungelöst, wird ein strukturiertes Support-Ticket für die IT vorbereitet.

## Geplante Funktionen

- Problemanalyse mit OpenAI und Gemini
- Gesprächsverlauf und kontextbezogene Rückfragen
- Support-Tickets über eine REST-API verwalten
- KI-Modelle und Prompt-Techniken vergleichen
- Optional: Wissensdatenbank mit RAG

## Technologien

Python · FastAPI · SQLite · SQLAlchemy · OpenAI · Gemini · Swagger UI
